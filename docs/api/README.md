# QuickClass DE 应用 API

本文档集合描述 cdapp 应用可使用的宿主 API。应用包格式、manifest、项目创建、开发调试和发布流程请参阅[应用开发文档](../apps.md)。

## API 文档

- [应用与壳层通信](bridge.md)：应用消息协议、底栏操作、宿主通知及桥接模块。
- [应用设置](settings.md)：应用隔离的持久化设置 API。

## 当前 API 状态

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 底栏操作 | 已实现 | 应用可注册操作，宿主通过 invoke 通知点击 |
| 可见性通知 | 已实现 | 宿主通知应用当前是否可见 |
| 应用设置 | 已实现 | 通过宿主桥接访问 SQLite 设置库 |
| 权限声明 | 仅元数据 | manifest.permissions 当前不执行授权 |
| 生命周期钩子 | 未提供 | 暂无正式的初始化、销毁回调 |
| API 版本协商 | 未提供 | 暂无 apiVersion / minHostVersion 检查 |

> 本文以仓库当前实现为准。尚未实现的能力会明确标注为规划或限制，不应被当作可调用 API。
